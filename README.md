# 旅ことば / TABI KOTOBA

面向日语专业学生的日本旅行与生活训练网站。当前为集成开发版；不将课程目录或未验证的外部服务算作完成。

## 运行

Node 22.13+，npm install、npm run dev。生产构建 npm run build；数据与逻辑检查 npm test，类型检查 tsc --noEmit。
保留 Sites 生成的 Vinext（Next.js 兼容）、React、TypeScript、Tailwind 和 shadcn 组件。

## 当前可用

- 首页、场景、对话、听力、广播、菜单、词典、生活、复习、个人设置与独立实景阅读页面。
- 747 条结构化学习内容，包括 128 个词条、39 道菜单；76 条可练习的本地对话流程。
- 独立预约专题：餐厅、酒店、巴士、景点、展览、美容院、私汤、新干线，以及变更和迟到沟通。
- 付款专题：信用卡感应与插卡、交通 IC 余额不足、二维码金额确认、领收书抬头；14 个补充支付词条。
- 5 组结构化表达对照，覆盖询价、要水、问路、拒绝袋子和说明预约；每句支持显示切换、发音、收藏和复习。
- HTML Ruby、原文、假名、罗马字、中文、日语解释、隐藏模式；四档速度及单句、连续、A–B 逐句循环。
- 场景课程按单元和页码阅读，区分顾客与工作人员表达。
- 8 种实景操作：酒店电梯、用品台、食券机、出口牌、IC充值机、储物柜、自动售货机和餐厅预约页面。
- 新干线任务包含车次、行李、选座、乘车凭证和站台车厢确认；列车时间和费用是模拟数据。
- 菜单拆词及食材、做法、味型、生熟含义四项测验；不把菜单名当成配料或熟度保证。
- 10 条广播行动测验，播放结束才开放答案，使用文字稿计为辅助作答。
- 5 组每日计划，每日八站，保存中途草稿与整日复盘。独立对话也自动保存未发送文字及进度。
- 突发实战独立入口：8个随机任务，隐藏异常详情与示例答案；按类别抽取，保存独立草稿并恢复最近8次实战。新增账单异议、早餐券遗失、错过叫号、IC入场记录缺失、走错车厢和快递无法及时送达流程。
- 复习到期数量定时更新；训练计时使用单调时钟，菜单四项测验按平均作答时长计入SRS。
- SRS 优先错误、慢答和辅助作答；AI 复盘推荐表达可进入个人词库与 SRS。
- LocalStorage备份导出与校验后恢复（含显示设置）；损坏记录先保存原始副本，无法备份时停止覆盖；导入失败回滚旧记录。PWA缓存已访问资源。
- 移除语音识别。可选录音仅供本机回听，不识别、不上传。

## AI 服务

私有 .env.local 已被 Git 排除。不要将密钥写进 NEXT_PUBLIC、页面源码、截图或提交记录。
DeepSeek：DEEPSEEK_API_KEY，DEEPSEEK_MODEL（默认 deepseek-v4-flash）。
兼容接口：TUTOR_API_URL、TUTOR_API_TOKEN、TUTOR_MODEL。仅在未配置原生 DeepSeek key 时使用。
服务端只接受现有场景与受限对话数据，校验所有返回字段、评分范围、日语注音，拒绝不完整响应。
切换场景取消待处理请求，失败保留回答。配置状态不等于凭证已验证。
2026-09-06更新密钥后已通过真实 DeepSeek 联调：酒店入住10个节点完成，结束后的复盘返回10条逐句评价及5个推荐表达。此结果证明本机当前连接可用，不保证后续所有模型输出都可靠。
在线模式由AI理解回答、处理澄清；完成目标时使用课程中已校对的下一步台词，避免遗漏事项和改写模拟规则。与课程示例完全相同的回答，以及意图和下一句都明确吻合的情况，使用确定性进度校验。
模型返回格式无效时最多修复一次；不会对密钥、余额、限流错误自动重复请求。振假名只能从课程内明确读音补齐，残缺标记和未知读音仍需修正。复盘只接受真实用户原句；无独立证据的听力、反应速度维度强制为null。
课程校对依据优先于模型对「予約している」和餐厅「水をください」的常见误判，并在页面显示来源标签。AI建议仍需结合语境判断，不能把一次返回当成人工语言学验收。
对话页可直接启用在线AI；成功复盘会保存，重复点击不会再次请求。

官方依据（2026-09-05核对）：
- https://api-docs.deepseek.com/api/create-chat-completion/
- https://api-docs.deepseek.com/guides/json_mode/

## 发音

浏览器只选择 ja-JP，并允许选择具体声音；localService 标识区分本机与浏览器提供的远程声音。声音供应和音质依设备/浏览器，不保证存在远程声音。
Azure原生：AZURE_SPEECH_KEY、AZURE_SPEECH_REGION、可选AZURE_SPEECH_VOICE（默认ja-JP-NanamiNeural）。
其他云端：TTS_API_URL、TTS_API_TOKEN；接收text/rate/language并返回audio/*。
独立云端尚未配置或实测。云端已生成的最近20条音频仅在当前页面内存复用，避免逐次循环重复请求。
预制真人/合成音频包尚未制作，不声称已提供真人录音。
参考：https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech

## 内容与真实性

data/*.json管理语料；[予約|よやく]安全转换成ruby/rt，无原始HTML执行。
language与现实rule分开：culture.json包含官方source、sourceUrl、lastVerified和适用范围；现场确认型memo不伪造官方出处。
频度是教学优先级，非语料库统计。自动罗马字是辅助转写，不能替代人工词法校对。
离线按关键信息和有限否定检查推进，不是语义模型。AI自然度无证据时不得编造分数。
N5至Native设置调整语速、提示及在线NPC复杂度；离线不是七套独立题库。
